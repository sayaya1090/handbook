# 문서-구현 불일치 및 구현 노트 (Discrepancy Log)

이 문서는 요구사항 및 설계 문서와 실제 코드 구현 간의 일시적인 불일치 또는 기술적 제약으로 인한 변형 사항을 기록합니다.

---

## 1. 세션 상태 모델 (SessionState)

| 항목 | 문서 상 정의 (docs/requirements.md) | 실제 구현 (shell-ui) | 상태 |
|------|---------------------------------|---------------------|------|
| **클래스 타입** | `sealed class` (Kotlin/Sealed) | `abstract class` | 🚧 기술 제약 (GWT 미지원) |
| **데이터 포함** | `Authenticated`, `InWorkspace` 가 사용자/워크스페이스 정보를 직접 소유 | 정적 상수 인스턴스만 제공. 실제 데이터는 `UserProvider`, `WorkspaceList` 를 통해 별도 조회 | 🚧 구현 단순화 |

**노트:** 현재 `SessionStateProvider`는 상태 전환 로직만 담당하며, 상태 객체 자체에 데이터를 담지 않습니다. 이는 상태 객체의 재사용성을 높이기 위함이나, 요구사항의 모델과는 차이가 있습니다.

---

## 2. Soft Delete 미구현 (기술 부채)

| 항목 | 요구사항 (7.5 UX 개선) | 실제 구현 (document-command) | 상태 |
|------|----------------------|----------------------------|------|
| **삭제 방식** | 즉시 삭제 대신 30일 보존 후 하드 삭제. 복구 가능. | 즉시 하드 삭제 (DELETE) | ❌ 미구현 |

**노트**: 요구사항 7.5항의 "UX 개선 — Soft Delete" 정책이 백엔드 저장 로직(`DocumentService`)에 반영되지 않았습니다. 현재는 삭제 요청 시 데이터가 즉시 삭제됩니다.

---

## 3. 검색 엔진 분석기 설정 불일치

| 항목 | 아키텍처 정의 (docs/architecture.md) | 실제 구현 (document-query) | 상태 |
|------|------------------------------------|----------------------------|------|
| **한글 분석기** | Nori(노리) 형태소 분석기 사용 명시 | 인덱스 매핑 및 검색 쿼리 설정 누락 | ❌ 불일치 |

**노트**: 한국어 검색 품질 고도화를 위해 명시된 Nori 분석기가 실제 Elasticsearch 인덱스 템플릿 및 `ElasticsearchQueryBuilder.java`에 반영되지 않았습니다. 기본 분석기를 사용 중입니다.

## 4. REST API 표준 준수 미흡 (응답 상태 코드)

| 항목 | 설계 표준 (docs/engineering-standards.md) | 실제 구현 (workspace-command 등) | 상태 |
|------|-----------------------------------------|-----------------------------------|------|
| **리소스 생성 응답** | `201 Created` 반환 권장 | `200 OK` 반환 중 | 🚧 보완 필요 |

**구체적 사례**: `WorkspaceController.create` 등 주요 POST API가 성공 시 `201` 대신 `200`을 반환함. 향후 일괄 리팩토링 및 `@ResponseStatus(HttpStatus.CREATED)` 적용 필요.

## 8. 자동 감사 규칙 (보완 예정)

- **에이전트 연동 섹션**: 모든 모듈의 `README.md`에 포함되었으나, `USECASE.md`의 시퀀스 다이어그램 정합성은 추가 검수가 필요함.
- **테스트 파일 확인**: `docs-keeper`가 보고한 "완료" 항목 중 일부는 실제 파일 경로와 클래스명이 미세하게 다를 수 있음 (예: `Application.java` vs `*Test.kt`).
- **GWT 도메인 JVM 호환성 (해결)**: `JsPropertyMap`을 포함한 도메인의 JVM 역직렬화 이슈가 `JsPropertyMapModule` 도입으로 해결됨 (2026-05-24).
- **타입 저장 낙관적 잠금 (해결)**: `Type` 모델의 `rev` 필드 누락으로 인한 저장 실패가 수정됨 (2026-05-12).
- **레이아웃 데이터 소실 (해결)**: GWT Proxy 객체가 백엔드에서 빈 JSON으로 직렬화되던 문제와 Spring Data R2DBC의 isNew 판정 오류(INSERT 대신 UPDATE 시도)가 해결됨 (2026-05-12).
- **UI 에러 처리 누락 (해결)**: 서버 에러 발생 시 UI에서 'Save completed'로 오인하던 버그가 API 클라이언트의 Promise 체인 보완으로 해결됨 (2026-05-12).
- **저장 후 리비전 동기화 (해결)**: `PATCH /schema` API가 저장된 최신 데이터를 반환하도록 수정하고 UI가 이를 즉시 반영하도록 하여, 저장 직후 작업 시 발생하던 409 Conflict 문제를 해결함 (2026-05-12).
